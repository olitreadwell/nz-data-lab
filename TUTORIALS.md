# Tutorials

One line per published tutorial — the cleaned-up, outside-reader writeup of an
experiment that worked well enough to teach from. Not every experiment gets a tutorial;
only add one once `apps/web/src/app/experiments/<slug>/TUTORIAL.md` is actually filled
in and worth someone else's time.

Format: `- [slug](apps/web/src/app/experiments/<slug>/TUTORIAL.md) — one-line hook`
