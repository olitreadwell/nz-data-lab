# _example — tutorial template

The outside-reader version. Goal #3 of nz-data-lab: turn what worked into something
someone else could actually follow. Write this last, after the experiment is done and
you know what actually mattered — not as a running log.

## What you'll build

One paragraph, plain language. Assume the reader has never seen this repo.

## Data source

Where the data comes from, how to get your own copy (a download link, an API call), and
any gotchas in the raw format (weird encodings, undocumented column meanings, rate
limits).

## Steps

Numbered, copy-pasteable where possible. Include real commands, real file paths. If a
step relies on a judgment call rather than a mechanical action, say so explicitly rather
than presenting it as a rote step.

## What actually happened

The honest part: what broke, what took longer than expected, what you'd do differently
starting over. This is the section that makes a tutorial useful instead of a sanitized
success story.

## Try it yourself

A concrete next step or variation the reader could try — a different region, a different
time window, a different dataset that pairs with this one.
